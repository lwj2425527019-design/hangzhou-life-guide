# 杭州未来30天北方人生活指南

这是一份可直接在 Windows 浏览器中打开的本地中文网页，覆盖 **2026年10月24日至2026年11月22日**。页面包含30天逐日生活重点、穿衣对照、家常菜单、睡眠与被褥、居家防潮、通勤检查和资料来源。

## 如何打开

1. 打开 Windows 文件资源管理器。
2. 进入本文件夹：
   `C:\Users\Administrator\Documents\Codex\2026-10-24\30-1-30-2-3-30`
3. 双击 `index.html`。
4. 页面会用默认浏览器打开。

不需要安装任何软件，也不需要启动服务器。推荐使用较新版本的 Microsoft Edge 或 Google Chrome。

如果双击后没有反应，可以右键 `index.html`，选择“打开方式”，再选择 Edge 或 Chrome。

## 文件作用

| 文件 | 作用 |
| --- | --- |
| `index.html` | 网页的完整结构、正文分区、导航和可访问性标签 |
| `styles.css` | 手机与电脑端布局、配色、表格、卡片和打印样式 |
| `data.js` | 30天日期内容、每周重点、穿衣表、菜单、食材、居家建议和来源链接 |
| `app.js` | 日期切换、菜单渲染、居家标签页、清单保存和可选天气刷新 |
| `README.md` | 打开方法、文件说明、更新方式和常见问题 |
| `sources.md` | 来源清单、查询日期、本次联网结果及信息不确定性说明 |

所有文件必须保持在同一文件夹，否则页面可能只显示未排版内容。

## 页面功能

- **按天查看**：点击日期卡或手机下拉框，查看当天的穿衣、饮食、睡眠和居家重点。
- **每日检查**：勾选状态保存在本机浏览器的 `localStorage` 中，不会上传。
- **居家标签**：切换晾衣、鞋袜、洗澡和防潮建议。
- **打印菜单**：点击“打印一周菜单”，仅打印菜单部分。
- **天气刷新**：点击“尝试刷新天气”可能会读取 Open-Meteo 的公开接口，并把成功结果暂存在本机浏览器。

## 天气数据如何处理

页面在制作时通过浏览器取得了 Open-Meteo 的 **16天公开模型预报**（查询时间：2026-10-24 14:07，覆盖至11月8日）。这段结果已写入 `data.js`，同时保留获取时间和非官方来源标签。第17—30天没有具体天气数值，按季节参考和不确定程度书写。

具体天气预报不是永久不变的。请以以下官方渠道为准：

- [中国天气网杭州页面](https://www.weather.com.cn/weather/101210101.shtml)
- [中国气象局](https://www.cma.gov.cn/)
- [国家突发事件预警信息发布网](http://www.12379.cn/)

天气刷新按钮依赖互联网与浏览器跨域策略。直接双击本地 HTML 时，部分浏览器可能阻止请求；失败不影响其他功能使用，页面会明确显示刷新失败并保留已有的16天参考数据。

## 如何更新内容

### 更新季节建议、菜单或每日文案

用普通文本编辑器打开 `data.js`，修改对应文本即可：

- `meta`：日期范围、天气状态和预报边界；
- `overview`：首页重点；
- `dailyPlans`：30天逐日内容；
- `weeks`：每周重点；
- `clothingTable`：穿衣对照表；
- `menu`：七天菜单；
- `shopping`：食材与采购清单；
- `sleepGuide`：被褥建议；
- `homeTips`：居家分类建议；
- `commute`：出门与通勤清单；
- `northComparison`：地域差异说明；
- `sources`：页面底部的来源链接。

编辑后保存，刷新浏览器即可。建议修改前复制一份备份。

### 更新天气

最简单的做法是打开页面点击“尝试刷新天气”，再与中国天气网核对。若浏览器阻止本地页面联网，直接点页面中的官方预报链接查看。

若要把某次天气固定写进本地文件，可更新 `data.js` 顶部的 `forecast16` 数组；若增加日期或调整字段，请同步检查 `app.js` 中的 `loadEmbeddedForecast`。同时在 `meta` 和 `sources.md` 中记录查询时间与来源。不要只更新温度而忘记注明来源。

### 滚动到新的30天

当前日期范围是固定的。进入新的30天时，需要同步修改：

1. `meta.startDate` 与 `meta.endDate`；
2. `dailyPlans` 的30个日期和对应内容；
3. `weeks` 的日期范围与周重点；
4. 页面顶部日期、`index.html` 中的静态日期文案；
5. `README.md` 和 `sources.md` 的覆盖日期。

## 信息与安全边界

- 页面不宣称任何食材能治疗疾病，也不推荐保健品。
- 睡眠舒适度存在个体差异；持续失眠、呼吸不适或其他健康问题应咨询专业人员。
- 出现持续渗漏、墙体霉害或结构潮湿时，应联系物业或专业人员处理。
- 页面无统计脚本、广告、登录、付款和上传功能，不会主动发送个人数据。
- 天气测试接口不是中国气象局官方预报，不能代替正式气象预警。

## 常见问题

**页面只有文字、没有样式？**

确认 `styles.css` 与 `index.html` 在同一文件夹，并刷新浏览器。

**日期区域没有生成？**

确认 `data.js` 与 `app.js` 均在同一文件夹，且浏览器启用了 JavaScript。

**刷新天气没有成功？**

这是允许出现的情况。直接打开中国天气网查询；网页其余内容仍可正常使用。

**打印出来包含整套页面？**

点击页面菜单区域的“打印一周菜单”，或者按 `Ctrl+P` 后检查是否选择了由页面预设的打印样式。
